# Tendrils setup

Generated from the two supplied Tendrils guides.

The documents require real Sanity credentials and Sanity-side configuration.
After generation, configure `.env.local`, Sanity CORS origins, and the
`/api/revalidate` webhook as described in the guides.

The redesign guide also references some page implementations from an earlier
TypeScript build that was not included in the supplied documents. Those
unseen files cannot be reproduced verbatim; all concrete code actually
present in the two supplied documents is extracted here.
